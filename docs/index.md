**Author:** Thomas Wieland  
**ORCID:** [0000-0001-5168-9846](https://orcid.org/0000-0001-5168-9846)  
**EMail:** [geowieland@googlemail.com](geowieland@googlemail.com)  
**Version:** 1.0.0 · 2026-11-14


This handbook aims to provide an overview of the methods and models for the spatial analysis of epidemic spreads, as implemented in my `R` package `swash`. However, it is NOT intended as a documentation of the functions. The Reference Manual [available on CRAN](https://cran.r-project.org/web/packages/swash/refman/swash.html) is intended for this purpose.

If you use this handbook, please cite:

Wieland T (2026) Spatial Analysis of Epidemic Waves using the `R` Package `swash`. [https://geowieland.github.io/swash_offical/](https://geowieland.github.io/swash_official/)
